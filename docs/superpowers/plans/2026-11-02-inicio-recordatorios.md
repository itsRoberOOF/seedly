# Inicio y recordatorios Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Persona 2's Inicio task feed and local task reminders while leaving Persona 1's CRUD/editing and Persona 5's watering logic to their owners.

**Architecture:** Add the minimum read-only `SeedlyTask`/repository contract required by Inicio, then keep all notification-plugin calls behind `SeedlyNotificationService`. A task-reminder coordinator reconciles future Firestore tasks with pending local notifications, while `SeedlyHomeScreen` combines the day query, Persona 4's plant state, and the existing `SeedlyPlant` widget.

**Tech Stack:** Flutter 3.47.7, Dart 3.13.5, Firebase/Firestore, `flutter_local_notifications` 22.3.3, `timezone` 0.11.0, `flutter_timezone` 5.1.1, `fake_cloud_firestore`, `flutter_test`.

**Spec:** `docs/superpowers/specs/2026-11-02-inicio-recordatorios-design.md`

## Global Constraints

- Work only on branch `Christopher`; do not create a PR or merge to `main`.
- Use small ordered commits with English Conventional Commit prefixes (`feat:`, `chore:`, `docs:`, `test:`, `fix:`, `merge:` when applicable).
- Do not implement Persona 1's project/task CRUD, edit screens, delete flows, or completion repository logic.
- Do not implement Persona 5's watering sessions or drops logic.
- Firebase SDK imports remain in `lib/data/`; screens receive dependencies by constructor.
- Every Firestore task query filters `ownerId` and stores date-only semantics as local calendar day plus `dueMinutes`.
- Reminder offsets are only 10, 30, or 60 minutes; past reminders are never scheduled.
- Android exact alarms must not crash when permission is unavailable; web is a no-op.
- Use `SeedlyTask.id` as the payload identity and cancel all task reminders on successful sign-out.

## Review Focus

- A task with a null date/time, completed state, null reminder, or past reminder must never be scheduled; cover in Task 1 tests.
- A task edited after scheduling must replace the old pending notification, including after process restart; cover in Task 3 tests.
- A Firestore query must not leak another user's tasks and must treat day end as exclusive; cover in Task 2 tests.
- Permission denial must preserve the task and report a non-granted result without scheduling; cover in Task 1 and Task 3 tests.
- Logout and notification payloads must not cross account/task boundaries; cover in Task 5 tests.
