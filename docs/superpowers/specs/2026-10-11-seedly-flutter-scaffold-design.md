# Seedly Flutter scaffold

## Goal

Initialize a Flutter application in the existing `seedly` repository.

## Scope

- Project name: `seedly`
- Target platforms: Android and iOS only
- Package identifier: `com.example.seedly` as a temporary default
- Use the standard Flutter project structure and generated starter app
- Do not add product features, dependencies, backend services, or design changes

## Success criteria

- The repository contains a valid Flutter project.
- `flutter pub get` completes successfully.
- Android and iOS project files are generated.
- Other Flutter platform folders are not generated.
- The generated project can be analyzed without errors.
